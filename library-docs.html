01 Library — корневой объект

Точка входа. Загружается через loadstring, кладёт себя в getgenv().Library и при повторном запуске выгружает предыдущую версию сама.

if getgenv().Library then
    getgenv().Library:Unload()
end
local Library = loadstring(game:HttpGet("https://raw.githubusercontent.com/treex1377333-creator/guiforraknet/refs/heads/main/source.lua"))()

▸ Поля

ПолеОписание
ThemeЦвета темы: Background, Inline, Element, Accent, Border, Border 2.
MenuKeybindКлавиша открытия/закрытия окна. По умолчанию Enum.KeyCode.Z.
FlagsТаблица [Flag] = значение — текущее состояние всех элементов.
SetFlagsТаблица [Flag] = function(value) для программной установки (используется конфигами).
Tween{Time, Style, Direction} — параметры анимаций по умолчанию.
FadeSpeedСкорость fade-анимации всплывающих окон (0.2 сек).
FoldersDirectory, Configs, Assets — создаются автоматически.
OpenFramesРеестр открытых всплывающих окон (для авто-закрытия остальных).

▸ Методы

Library:Unload()

Отключает все соединения, останавливает все потоки, уничтожает интерфейс и обнуляет getgenv().Library.

Library:Round(Number, Float)

Округляет число с заданным шагом: Library:Round(3.14159, 0.01) → 3.14.

Library:Thread(Function)

Запускает функцию в отдельной корутине, регистрирует её для закрытия при Unload.

Library:SafeCall(Function, ...)

pcall-обёртка: при ошибке пишет warn и возвращает false. На неё опираются все колбэки элементов.

Library:Connect(Event, Callback, Name)

Подписка на событие с сохранением соединения в реестре — для последующего Disconnect или массовой отписки при Unload.

Library:Disconnect(Name)

Отключает соединение по имени.

Library:NextFlag()

Генерирует уникальный флаг вида flag_number_N_GUID для элементов без явного Flag.

Library:AddToTheme(Item, Properties)

Регистрирует свойства инстанса как «привязанные к теме» — значение либо ключ из Library.Theme, либо функция.

Library:ChangeItemTheme(Item, Properties)

Меняет набор темизированных свойств у уже зарегистрированного элемента (например, временная подсветка кнопки).

Library:ChangeTheme(Theme, Color)

Меняет цвет темы и мгновенно применяет его ко всем элементам, зарегистрированным на этот ключ.

Library:ToRich(Text, Color)

Оборачивает текст в <font color="rgb(...)"> на основе Color3.

Library:GetConfig() / Library:LoadConfig(Json)

Сериализация/восстановление всех Flags в JSON. Подробнее — раздел Конфиги.

Library:DeleteConfig(FileName) / Library:RefreshConfigsList(Dropdown)

Удаление файла конфига и обновление списка конфигов в переданном Dropdown-элементе.

Library:IsMouseOverFrame(Frame) / Library:IsClipped(Object, Column)

Геометрические проверки: находится ли курсор над Frame, выходит ли элемент за границы колонки (используются для авто-закрытия всплывающих окон).

Library:Lerp(Start, Finish, Time)

Линейная интерполяция.

Library:CreateColorpicker(Data) / Library:CreateKeybind(Data)

Низкоуровневые конструкторы. На практике вызываются через Toggle:Colorpicker{}, Label:Keybind{} и т.п. — см. разделы Colorpicker и Keybind.

Library:Notification(Name, Duration, Icon)

Показывает всплывающее уведомление. См. Notification.

Library:Window(Data)

Создаёт главное окно. См. Window.

Library:Category(Name)

Добавляет неинтерактивную текстовую подпись-разделитель в список страниц сайдбара.

Library:CreateSettingsPage(Window)

Автоматически создаёт готовую страницу настроек (конфиги, темизация, скорость анимаций). См. Settings-страница.

02 Tween — модуль анимаций

Внутренний класс, напрямую не экспортируется — используется через Instances:Tween(...) на любом созданном элементе.

  • Tween:Create(Item, Info, Goal, IsRawItem) — создаёт и запускает TweenService:Create.
  • Tween:GetProperty(Item) — возвращает свойства прозрачности, применимые к типу инстанса.
  • Tween:FadeItem(Item, Property, Visibility, Speed) — плавный показ/скрытие свойства.
  • Tween:Get() / Tween:Pause() / Tween:Play() / Tween:Clean() — управление созданной анимацией.

03 Instances — обёртка над Instance.new

Каждый созданный GUI-объект в библиотеке — таблица {Instance = <RobloxInstance>} с методами:

:Create(Class, Properties)
создаёт Instance и применяет свойства
:AddToTheme(Properties)
привязка к теме
:Connect(Event, Cb, Name)
подписка на событие
:Tween(Info, Goal)
анимация свойств
:Clean()
Destroy()
:MakeDraggable()
перетаскивание мышью/тачем
:MakeResizeable(Min, Max)
ресайз за правый нижний угол
:OnHover / :OnHoverLeave
события наведения курсора

04 Window

Создаётся через Library:Window{...}. Перетаскиваемое и растягиваемое окно, открывается по центру экрана.

Поле DataПо умолч.Описание
Name"Window"Заголовок
SubTitle"he"Подзаголовок (например, название игры)
ExpiresIn"23d"Текст в нижнем блоке сайдбара
IconrbxassetidИконка в заголовке
  • Window:Page(Data) — создать страницу (вкладку сайдбара).
  • Window:SetCenter() — пересчитать позицию после смены anchor (авто-вызов).
  • Window:Visible(Bool) — мгновенный показ/скрытие.
  • Window:SetOpen(Bool) — плавное открытие/закрытие; вызывается по MenuKeybind.

05 Page

Window:Page{ Name = "...", Icon = "rbxassetid" } — вкладка в левом сайдбаре.

  • Page:SubPage(Data) — создать под-вкладку.
  • Page:Visible(Bool) — показать/скрыть кнопку страницы.
  • Page:Turn(Bool) — активировать/деактивировать (первая созданная активна по умолчанию).

06 SubPage

Page:SubPage{ Name = "...", Columns = 2 } — горизонтальный переключатель вверху контента; задаёт число колонок для секций.

  • SubPage:Visible(Bool)
  • SubPage:Turn(Bool)
  • SubPage:Section(Data) — создать секцию в одной из колонок.

07 Section

SubPage:Section{ Name = "...", Icon = "id", Side = 1 } — блок-карточка, контейнер для элементов управления. Side — номер колонки.

Section:Visible(Bool) — показать/скрыть всю секцию целиком.

08 Toggle

Section:Toggle({
    Name = "Aim FOV",
    Flag = "AimFov",
    Default = false,
    Callback = function(Value) end

  • Toggle:Set(Value) — установить + анимация + Callback
  • Toggle:SetVisibility(Bool) / :Visible(Bool)
  • Toggle:Colorpicker(Data) — прикрепить colorpicker справа
  • Toggle:Keybind(Data) — прикрепить keybind справа

09 Button

Section:Button({
    Name = "Reset",
    Callback = function() end
})
  • Button:SetVisibility(Bool) / :Visible(Bool)
  • Button:Press() — программно «нажать»: подсветка акцентом на 0.1с + Callback

10 Slider

Min / MaxГраницы значений

11 Dropdown

local Dropdown = Section:Dropdown({
    Name = "Weapon",
    Items = {"AK-47", "M4A1", "AWP"},
    Default = "AK-47",
    Multi = false,
    Flag = "Weapon",
    Callback = function(Value) end
})
  • Dropdown:Get() / Dropdown:Set(Option)
  • Dropdown:Add(Option) / Dropdown:Remove(Option)
  • Dropdown:Refresh(List) — пересобрать весь список опций
  • Dropdown:SetOpen(Bool) — открыть/закрыть программно
  • Dropdown:SetVisibility(Bool) / :Visible(Bool)

Multi = true — множественный выбор, Value становится таблицей.

14 Colorpicker

Создаётся не напрямую, а через Toggle:Colorpicker{} / Label:Colorpicker{}.

Section:Toggle({Name = "ESP", Flag = "ESP"}):Colorpicker({
    Flag = "ESPColor",
    Default = Color3.fromRGB(255, 0, 0),
    Callback = function(Color, Alpha) end
})
  • Colorpicker:Get() → Color3
  • Colorpicker:Set(Color, Alpha) — принимает Color3, hex-строку или {R,G,B,Alpha}
  • Colorpicker:SetOpen(Bool) — палитра насыщенность/яркость + полоса оттенка
  • Colorpicker:SetVisibility(Bool) / :Visible(Bool)

15 Keybind

Section:Toggle({Name = "Aimbot", Flag = "Aimbot"}):Keybind({
    Flag = "AimbotKey",
    Default = Enum.KeyCode.Q,
    Mode = "Hold", -- "Toggle" | "Hold" | "Always"
    Callback = function(IsActive) end
})
РежимПоведение
ToggleНажатие переключает вкл/выкл
HoldАктивно, пока клавиша зажата
AlwaysАктивно всегда после назначения клавиши
  • Keybind:Get() → Key, Mode, Toggled
  • Keybind:Set(Key) — EnumItem, либо {Key, Mode}, либо строка режима
  • Keybind:SetMode(Mode)
  • Keybind:SetOpen(Bool) — открывается ПКМ, назначение новой клавиши ЛКМ

16 Notification

Library:Notification("Загрузка завершена", 4, "91306356501736")

Карточка с текстом и опциональной иконкой в верхней области экрана; исчезает сама через Duration секунд.

17 Конфиги

  • Library:GetConfig() — сериализует все Library.Flags в JSON.
  • Library:LoadConfig(Json) — применяет значения через SetFlags.
  • Library:DeleteConfig(FileName) — удаляет файл из Folders.Configs.
  • Library:RefreshConfigsList(Dropdown) — обновляет список файлов в Dropdown.

Файлы читаются/пишутся через writefile / readfile / delfile в папке Crown/Configs.

19 Полный пример

local Library = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/.../source.lua"
))()

local Window = Library:Window({
    Name = "Example", SubTitle = "game.PlaceId",
    ExpiresIn = "lifetime", Icon = "8508980536"
})

local MainPage = Window:Page({ Name = "Main", Icon = "136879043989014" })
local MainSub  = MainPage:SubPage({ Name = "General", Columns = 2 })
local Combat   = MainSub:Section({ Name = "Combat", Side = 1 })

Combat:Toggle({
    Name = "Aimbot", Flag = "Aimbot", Default = false
}):Keybind({ Flag = "AimbotKey", Default = Enum.KeyCode.Q, Mode = "Hold" })

Combat:Slider({ Name = "FOV", Min = 10, Max = 500, Default = 100, Flag = "AimFov" })

Library:CreateSettingsPage(Window)
Library:Notification("Скрипт загружен!", 3)
Флаги (Flag) должны быть уникальны в пределах окна — по ним хранится значение в Library.Flags и сохраняется/загружается конфиг. Меню открывается клавишей Z по умолчанию.
